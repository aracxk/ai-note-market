## ADR 運用ルール

1. **新規作成時**:
   - `docs/03-adr/XXXX-title.md`（4桁連番）でファイルを作成する。
   - 本一覧（`docs/03-adr/README.md`）にID・タイトル・ステータス・概要を追記する。
2. **ステータス定義**:
   - `提案中 (Proposed)`: 検討中の設計案。
   - `承認済 (Accepted)`: 採択され、実装に反映された設計。
   - `置換済 (Superseded)`: 後のADRによって上書き・破棄された古い決定。
